# EM-AI AI 智能设备管理系统 — 产品设计文档

> **版本：** v1.0  
> **日期：** 2026-06-09  
> **角色视角：** 产品设计专家 + 全栈工程师 + 高级项目经理  
> **核心定位：** 基于 TPM（全面生产维护）管理体系，融合 AI 预测性维护能力，打造从"被动救火"到"主动健康管理"的设备全生命周期智能管理平台。

---

## 一、产品概述

### 1.1 产品定位

EM-AI 是一套面向离散制造/流程制造企业的 **AI 驱动的设备智能管理系统**，核心使命是实现设备管理从"故障后维修"到"预测性维护"的模式转变。

**与传统 EAM/TPM 系统的本质区别：**
- 传统系统 = 电子台账 + 工单流转（记录过去）
- EM-AI = 实时监测 + AI 预测 + 智能决策（预见未来）

### 1.2 目标用户与角色

| 角色 | 核心诉求 | 高频使用模块 |
|------|----------|-------------|
| **设备主管/经理** | 整体设备效率、KPI 达成、成本管控 | 效率看板、AI 分析、工治具管理 |
| **维修工程师** | 快速定位故障、精准维保、知识传承 | 故障处理、AI 预测、工治具管理 |
| **一线操作员** | 简单报修、日常点检、操作指导 | 故障申报、点检管理、保养执行 |
| **生产主管** | 设备可用性保障、产能计划匹配 | 效率看板、流失分析 |
| **企业决策层** | 投资回报率、设备资产健康度 | 全局仪表盘、寿命分析 |

### 1.3 核心设计理念

- **TPM 为体：** 全员参与、预防为主、三全（全效率/全系统/全员参与）
- **AI 为用：** 预测性维护、智能编排、异常检测、根因分析
- **数据驱动：** 从 OEE 六大损失出发，每个功能模块都对应可量化的改善指标
- **闭环管理：** 发现 → 决策 → 执行 → 验证 → 优化，形成持续改善循环

## 二、A. 故障管理

### 2.1 故障管理 — 状态管理

#### 业务场景

设备在工厂中处于动态变化的状态，管理层需要实时掌握每台设备的运行状况，操作员需要快速了解设备是否可用。

#### 功能设计

**A1. 设备状态全景看板**

- **实时状态展示：** 运行中 / 待机 / 换型中 / 故障 / 保养中 / 停机检修
- **状态定义与分类：**
  - 运行（Running）：正常生产
  - 待机（Idle）：设备正常但无生产任务
  - 换型（Changeover）：产品切换/模具更换
  - 故障（Down）：突发故障停机
  - 保养（Maintenance）：计划内保养执行中
  - 检修（Repair）：故障维修中
  - 报废（Retired）：已报废/待处置
- **状态时间线：** 每台设备可追溯完整状态变更历史，精确到秒
- **状态统计：** 按日/周/月统计各状态时长占比，自动计算设备可用率

**A2. 状态规则引擎**

- 支持自定义状态切换规则（如：连续 N 次报警自动切换为"故障"状态）
- 支持设备分组状态聚合（产线 → 车间 → 工厂三级汇总）
- 状态变更自动触发通知（企业微信/钉钉/短信）

**A3. 异常检测（AI 增强）**

- 基于 IoT 传感器数据，AI 实时检测设备运行异常（振动、温度、电流等参数偏离正常范围）
- 异常状态自动标记并推送告警，无需等待人工报修
- 异常严重程度分级（提示 / 警告 / 严重 / 紧急）

### 2.2 故障管理 — 故障申报

#### 业务场景

设备突发故障时，一线操作员需要快速上报，系统需要自动派单给合适的维修人员，同时记录完整的故障信息用于后续分析。

#### 功能设计

**A4. 多端故障申报**

- **扫码报修：** 设备二维码 → 一键报修，自动带出设备编号、位置、最近维修记录
- **语音报修：** 支持语音输入故障描述，AI 自动转文字并提取关键信息
- **拍照/视频上报：** 现场拍照或短视频，AI 辅助识别故障类型
- **IoT 自动上报：** 设备异常时系统自动创建故障工单，无需人工操作

**A5. 智能故障分类**

- 故障类型树：机械 / 电气 / 液压 / 气动 / 软件 / 其他
- 故障等级：P0（紧急停产）/ P1（严重降速）/ P2（轻微异常）/ P3（观察项）
- 故障原因编码：支持标准故障码库（基于 FMEA 故障模式库）
- AI 推荐分类：根据描述自动推荐故障类型和等级

**A6. 工单自动派发**

- 基于设备类型、故障等级、维修人员技能矩阵、当前工作量，智能匹配最优维修人员
- 支持派单规则配置（按区域 / 按专业 / 按班次轮值 / 按负载均衡）
- 升级机制：N 分钟内未接单 → 自动升级至上级主管

**A7. 报修信息模板**

- 结构化表单：设备 → 故障现象 → 故障等级 → 影响范围 → 附件
- 智能字段：根据设备类型动态展示相关字段（如注塑机展示温度/压力字段，CNC 展示主轴状态字段）
- 历史关联：自动关联该设备近 30 天故障记录、当前保养计划执行状态

### 2.3 故障管理 — 故障处理

#### 业务场景

维修人员接单后需要快速定位故障原因并修复，系统需要提供完整的维修流程管理和知识沉淀能力。

#### 功能设计

**A8. 维修工单全流程**

```
接单 → 现场诊断 → 方案制定 → 维修执行 → 备件领取 → 修复验证 → 完工确认 → 满意度评价
```

- **移动端维修界面：** 维修人员通过手机/平板接收工单，查看设备信息、历史维修记录、维修 SOP
- **维修过程记录：** 实时记录维修步骤、耗时、更换备件、维修前后对比照片
- **协作机制：** 复杂故障可邀请远程专家视频连线，支持多人协同维修
- **SLA 管理：** 按故障等级设定响应时间和修复时间 SLA，超时自动预警

**A9. AI 辅助诊断**

- **故障知识库匹配：** 根据故障现象自动匹配历史相似故障案例，推荐解决方案
- **AI 故障诊断：** 基于设备运行数据和故障描述，AI 模型分析可能根因并给出概率排序
- **维修方案推荐：** 根据故障类型和严重程度，推荐标准维修方案和操作步骤
- **备件预检：** 诊断同时推荐可能需要的备件清单，提前准备

**A10. 根因分析（RCA）**

- **5-Why 分析法：** 系统引导维修人员逐层追问，直到找到根本原因
- **鱼骨图分析：** 自动生成人/机/料/法/环/测维度的因果分析图
- **帕累托分析：** 自动统计各类故障的频次和影响，识别 TOP 问题
- **改善建议生成：** 基于根因分析结果，自动生成预防性改善建议

**A11. 维修知识沉淀**

- 每次维修完成后，系统自动将维修过程转化为知识条目（故障现象 → 原因 → 解决方案）
- 知识条目经审核后入库，形成可搜索的维修知识库
- 新人维修时，系统自动推送相关知识条目

## 三、B. 预防管理

### 3.1 预防管理 — 点检管理

#### 业务场景

TPM 的核心是"自己的设备自己保养"，一线操作员需要按照标准进行日常点检，及时发现设备异常苗头。

#### 功能设计

**B1. 点检标准管理**

- **点检层级：** 日常点检（每班）/ 定期点检（每周/每月）/ 精密点检（季度/半年）
- **点检项目库：** 按设备类型预设标准点检项目（温度、振动、油位、紧固件、清洁度等）
- **点检标准定义：** 每项点检对应正常范围、检测方法、判定标准
- **SOP 关联：** 每个点检项关联操作指导书（图文/视频）

**B2. 移动端点检执行**

- **扫码点检：** 扫设备二维码进入点检页面，自动带出该设备的点检项目
- **点检方式：** 数值录入（温度 85°C）/ 布尔判断（正常/异常）/ 拍照上传
- **异常自动触发：** 点检发现异常 → 自动创建故障工单 → 通知维修人员
- **防漏检机制：** 到点未点检 → 自动提醒 → 超时未点 → 上报主管

**B3. 点检计划与排程**

- 自动根据设备类型、运行时长、历史故障率动态调整点检频率
- 支持日历视图查看全厂点检计划
- 支持批量排程（如：每周一上午全员点检）

**B4. 点检数据分析**

- 点检完成率统计（个人/班组/车间/全厂）
- 点检异常趋势分析（哪些设备/项目频繁异常）
- 点检质量评估（点检人员一致性分析、漏检/误判率）
- 基于点检数据的设备健康度评分

**B5. AI 智能点检优化（增强）**

- **异常点检项预测：** 基于设备运行数据，AI 预测哪些点检项可能异常，优先检查
- **点检频率优化：** 基于设备健康趋势，动态推荐最优点检频率
- **点检标准优化：** 基于历史点检数据与故障关联分析，识别无效点检项和缺失点检项

### 3.2 预防管理 — 保养管理

#### 业务场景

设备需要定期保养以维持最佳状态，传统保养计划往往"一刀切"，缺乏针对性。EM-AI 通过 AI 实现差异化、精准化的保养策略。

#### 功能设计

**B6. 保养计划管理**

- **保养类型：** 日常保养 / 一级保养 / 二级保养 / 大修保养
- **触发方式：**
  - **时间触发：** 每隔 N 天/月/季度
  - **运行时长触发：** 设备运行 N 小时后
  - **产量触发：** 每生产 N 件后
  - **状态触发：** AI 检测到设备健康度低于阈值时
- **保养内容模板：** 按设备类型预设标准保养项目清单
- **保养资源规划：** 保养所需备件清单、工具清单、人员技能要求、预计工时

**B7. 保养工单管理**

- 自动根据保养计划生成保养工单
- 工单派发 → 保养执行 → 结果记录 → 验收确认 → 归档
- 保养过程拍照/视频记录，形成设备保养履历
- 保养异常自动升级（如：保养中发现重大隐患 → 自动转故障工单）

**B8. 保养效果评估**

- 保养前后设备状态对比（振动值、温度、精度等关键参数）
- 保养成本统计（工时 + 备件消耗）
- 保养后故障率变化追踪
- 保养策略优化建议（哪些保养项过度/不足）

**B9. AI 预测性保养（核心差异化）**

- **设备健康度模型：** 基于传感器数据 + 历史故障数据，构建每台设备的健康度评分模型
- **故障寿命预测：** 预测关键部件的剩余使用寿命（RUL - Remaining Useful Life）
- **保养时机推荐：** 不是"到时间就保养"，而是"在最佳时机保养" — 平衡过早保养浪费和过晚保养风险
- **多设备保养协同：** 当多台设备需要保养时，AI 自动推荐最优保养窗口（如：利用换型间隙、批次切换期）

## 四、C. 效率管理

### 4.1 效率管理 — 流失管理

#### 业务场景

OEE 是设备综合效率的核心指标，其本质是揭示和量化"六大损失"。效率管理模块将六大损失可视化、可量化、可追踪。

#### 功能设计

**C1. OEE 实时计算与展示**

```
OEE = 可用率 × 性能率 × 质量率
```

- **可用率：** 实际运行时间 / 计划运行时间
  - 反映：故障停机、换型换线、等待物料等时间损失
- **性能率：** 实际产量 / 理论最大产量
  - 反映：短暂停机、速度降低等性能损失
- **质量率：** 合格品数量 / 总产量
  - 反映：废品、返工、启动损失等质量损失

**C2. 六大损失可视化**

| 损失类型 | 分类 | 量化指标 |
|----------|------|----------|
| **设备故障** | 计划外停机 | 故障次数、故障停机时长、MTBF |
| **换型/调整** | 计划内停机 | 换型次数、换型平均时长、SMED 改善率 |
| **短暂停机** | 性能损失 | 短暂停机次数/时长、微停机频率 |
| **速度降低** | 性能损失 | 实际速度 vs 设计速度、速度损失率 |
| **废品/返工** | 质量损失 | 废品率、返工率、质量损失金额 |
| **启动损失** | 质量损失 | 启动阶段废品数、达到稳定产量所需时间 |

**C3. 损失追踪与归因**

- 每次停机/异常都需记录原因代码（标准原因码库 + 自定义）
- 支持多级原因分类（一级：故障/换型/速度/废品；二级：具体原因）
- 自动关联相关数据（停机时段的生产记录、保养记录、人员信息）

**C4. 损失趋势与对比**

- 按日/周/月展示六大损失趋势
- 设备间对比、班组间对比、产线间对比
- 改善活动前后对比（如：SMED 项目前后的换型时间对比）
- 行业基准对比（如：OEE 与行业平均水平的差距）

### 4.2 效率管理 — 流失分析

#### 业务场景

管理层需要深入分析效率损失的根因，识别改善机会，制定针对性的改进计划。

#### 功能设计

**C5. 帕累托分析（Pareto）**

- 自动识别造成最大损失的 TOP 3 原因（80/20 法则）
- 按设备/班组/班次/产品类型多维度帕累托分析
- 改善优先级建议：优先解决影响最大的问题

**C6. 根本原因分析工具**

- **时间序列分析：** 分析故障/停机的时间分布规律（如：是否集中在某班次、某时间段）
- **关联分析：** 故障与设备参数、环境参数、操作人员、物料批次的关联分析
- **趋势预测：** 基于历史数据预测未来效率走势

**C7. 改善项目管理**

- 针对识别出的改善机会，创建专项改善项目
- 设定改善目标（如：将换型时间从 45 分钟缩短到 20 分钟）
- 追踪改善进度，记录改善措施和效果
- 改善成果标准化 → 更新 SOP / 点检标准 / 保养计划

**C8. 效率看板（Andon + Dashboard）**

- **车间看板：** 实时展示各设备 OEE、当前状态、当日损失统计
- **移动端看板：** 主管可随时查看全厂效率概览
- **异常推送：** OEE 低于阈值时自动推送告警
- **交接班汇总：** 自动生成班次效率报告，便于交接

## 五、D. 工治具管理

### 5.1 工治具管理

#### 业务场景

工装夹具/模具/刀具是生产过程中的关键消耗资源，管理不当会导致产品质量不稳定、生产效率下降、成本上升。

#### 功能设计

**D1. 工治具全生命周期管理**

```
采购入库 → 编号建档 → 领用分配 → 使用跟踪 → 维护保养 → 寿命监控 → 报废处置
```

- **一物一码：** 每个工治具赋予唯一身份标识（二维码/RFID），扫码即可查询完整履历
- **档案信息：** 规格型号、供应商、采购日期、使用寿命、关联设备、保养标准
- **储位管理：** 记录当前存放位置（治具库 / 某设备 / 某班组），支持储位搜索

**D2. 工治具使用跟踪**

- **领用/归还流程：** 扫码领用 → 绑定设备/产品 → 使用完成 → 扫码归还
- **使用记录：** 每次使用的设备、产品、数量、操作人员、使用时长
- **异常记录：** 使用中发现的磨损、变形、精度偏差等问题自动记录
- **借用管理：** 支持跨班组/跨车间借用，追踪借用状态和归还期限

**D3. 工治具状态管理**

- 状态定义：在库 / 在用 / 保养中 / 维修中 / 报废 / 待检
- 状态变更自动记录并通知相关人员
- 超期未归还自动提醒和升级

**D4. 工治具保养管理**

- 基于使用次数/时长/时间的保养计划自动生成
- 保养项目标准化（清洁、润滑、精度检测、磨损检查）
- 保养记录与工治具档案关联，形成完整保养履历

**D5. 工治具库存管理**

- 安全库存预警：在库数量低于安全库存时自动提醒采购
- 库存盘点：支持定期盘点和随机抽查
- 周转率分析：识别闲置工治具，优化库存结构

### 5.2 工治具管理 — 寿命分析

#### 业务场景

工治具有理论使用寿命，但实际寿命受使用条件、保养质量、材料批次等因素影响。精确预测寿命可避免过早报废浪费和过晚使用导致的质量问题。

#### 功能设计

**D6. 寿命模型**

- **理论寿命：** 基于供应商数据、材料特性、使用条件的理论寿命（如：刀具 10000 次切削、模具 50 万模次）
- **实际寿命追踪：** 每次使用后记录实际使用数据（切削次数、压力值、温度等），与实际寿命对比
- **寿命衰减曲线：** 基于历史数据绘制寿命衰减曲线，识别加速衰减的模式

**D7. 剩余寿命预测（AI 增强）**

- **多因素寿命预测模型：** 综合考虑使用次数、使用条件、保养记录、材料批次等因素
- **实时剩余寿命显示：** 每个工治具显示剩余寿命百分比和预计可用天数/次数
- **提前预警：** 剩余寿命低于阈值时自动预警，触发保养或更换流程
- **异常寿命检测：** 实际寿命远低于预期寿命时，自动分析原因（是否操作不当、保养缺失、材料问题）

**D8. 寿命成本分析**

- 单件产品工治具成本 = 工治具采购成本 / 实际总产量
- 寿命 vs 成本关联分析：延长寿命是否划算？更换新件 vs 继续使用的成本对比
- 供应商寿命对比：不同供应商/批次的工治具实际寿命对比，指导采购决策

**D9. 寿命优化建议**

- 基于寿命分析数据，推荐最优更换时机（不是"到期就换"，而是"在性价比最优时换"）
- 识别可修复再利用的工治具，降低更换频率
- 基于寿命数据优化保养策略（哪些保养项对延长寿命最有效）

## 六、E. AI 智能分析

### 6.1 AI 智能分析 — 设备故障预测

#### 业务场景

传统设备管理是"坏了再修"或"定时保养"，EM-AI 通过 AI 实现"预测性维护" — 在故障发生前就预测到潜在问题，提前安排维护。

#### 功能设计

**E1. 设备健康度评分**

- **多维健康指标：** 基于振动、温度、电流、噪音、油液分析等多维度传感器数据
- **健康度模型：** 为每台关键设备建立健康度评分模型（0-100 分）
- **健康度趋势：** 展示健康度随时间的变化趋势，识别加速劣化的设备
- **阈值告警：** 健康度低于设定阈值时自动告警

**E2. 故障预测模型**

- **故障类型预测：** 预测可能发生的具体故障类型（轴承磨损、主轴过热、液压泄漏等）
- **故障时间预测：** 预测故障发生的时间窗口（如：未来 7 天内有 85% 概率发生）
- **故障严重程度预测：** 预测故障的影响程度（轻微/严重/灾难性）
- **置信度评估：** 每次预测附带置信度评分，帮助判断是否值得干预

**E3. 异常检测**

- **无监督异常检测：** 不依赖历史故障标签，自动检测运行模式的异常偏离
- **多变量关联异常：** 检测多个参数之间的异常关联（如：温度升高但振动正常 — 可能是冷却系统问题）
- **渐进式异常检测：** 识别缓慢劣化的趋势（如：振动值每周递增 2%，虽未超阈值但趋势异常）

**E4. 根因分析（AI 增强）**

- **故障传播分析：** 当多个设备同时异常时，AI 分析故障传播路径，识别源头设备
- **参数贡献度分析：** 分析哪些传感器参数对当前异常贡献最大
- **历史相似案例匹配：** 匹配历史相似工况下的故障案例，提供参考

### 6.2 AI 智能分析 — 维保计划智能编排

#### 业务场景

工厂同时运行数十上百台设备，需要安排多种类型的保养任务。人工排程往往顾此失彼，AI 可以综合考虑设备优先级、资源可用性、生产计划等多重约束，生成最优维保计划。

#### 功能设计

**E5. 多目标智能排程**

- **优化目标：**
  - 最大化设备综合效率（OEE）
  - 最小化非计划停机时间
  - 最小化维保成本
  - 平衡维修团队工作负载
  - 最小化对生产计划的影响
- **约束条件：**
  - 设备优先级（A/B/C 类设备差异化对待）
  - 维保资源限制（人员数量、技能、工具可用性）
  - 备件库存限制
  - 生产计划冲突（不能在生产高峰期安排大修）
  - 法规/安全要求（某些设备有法定保养周期）

**E6. 维保窗口推荐**

- **空闲窗口识别：** AI 自动识别设备的空闲时段（换型间隙、批次切换、计划停机）
- **窗口匹配：** 将维保任务匹配到最合适的空闲窗口
- **窗口利用优化：** 当多个维保任务可合并时，推荐合并执行以节省切换时间

**E7. 维保资源优化**

- **人员调度：** 根据维保任务所需技能和紧急程度，智能分配维修人员
- **备件预配：** 根据维保计划提前准备所需备件，避免"等备件"
- **工具/设备协调：** 确保维保所需的专用设备/工具可用

**E8. 维保效果反馈闭环**

- 维保完成后，系统自动追踪维保效果（后续故障率是否降低、健康度是否提升）
- 基于反馈数据持续优化预测模型和排程策略
- 维保策略 A/B 测试：对比不同维保策略的效果
